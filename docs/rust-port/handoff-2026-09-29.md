## 후속 작업 기록

### 2026-10-14 — win32.rs 복구 완료 (include! 청크 방식)

- MCP 단일 파일 업로드 한도 때문에 `win32.rs`를 `win32_p*.rs` 청크로 나누어 `include!`로 리버스 업로드 완료.
- 모든 `win32_p0_0.rs` ~ `win32_p2_1_2.rs` 청크가 정상 크기로 `crates/system-monitor-windows/src/`에 존재.
- GPU Settings 콤보는 `enumerate_gpus` / LUID 연동되어 있음.
- 로컬 작업 없이 원격에서 복구 완료.

### 2026-10-13 — CI 정책 변경 (Windows 러너 분 절약)

- `.github/workflows/rust.yml`에서 **Win32 layered-window smoke 스텝을 제거**했다.
- 이유: `windows-2022` 헤드리스 세션에서 `SendInput` 기반 드래그가 안정적으로 동작하지 않았고, 러너 분을 소모했다.
- CI에 남는 것: `cargo fmt`, Clippy (`-D warnings`), `cargo test`, MSVC release build, 포터블 디렉터리/ZIP/SHA256 artifact.
- GUI 수용(드래그, 잠금, 스냅, 멀티 모니터, DPI, 메뉴/Settings)은 [`evidence/p1-windows-run-checklist.md`](evidence/p1-windows-run-checklist.md) 로컬 Windows 11 체크리스트로만 수행한다.

## 현재 코드 상태 요약 (Phase 기준)

- **Phase 0–1**: Win32 오버레이 + Settings PoT 구조 완료. `include!` 기반 소스 정상.
- **Phase 2**: 설정 저장/불러오기, 시작 프로그램, 단일 인스턴스, Appearance/Devices 창 전부 구현됨.
- **Phase 3**: CPU/RAM/Network/Disk 텔레메트리 (`sysinfo` + PDH) 구현. 어댑터 선택, 디스크 다중 선택 지원.
- **Phase 4**: GPU enumeration (`nvidia-smi` + PDH LUID), `resolve_selection`, NVIDIA/AMD 샘플링, D3DKMT 온도 구현.
- **Phase 5**: 오버레이 렌더링, 컨텍스트 메뉴, 스냅/프리, 풀스크린 감지, DPI 스케일 기본 구현.
- **Phase 6–7**: 통합 검증은 로컬 W11 필요. 포장 패키지 CI에서 생성 가능.
